An enterprise-grade integration engine that connects to SAP Subscription Billing microservices 
(Bills, Subscriptions, Products, Rate Plans, Usage Records). Features automated OpenAPI 3.0 schema 
inference, dynamic Jackson POJO compilation, ANSI SQL check-then-upsert persistence, and an 
Ordinary Least Squares (OLS) machine learning model for future revenue and customer churn forecasting.
